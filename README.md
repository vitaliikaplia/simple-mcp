# Simple MCP

WordPress-плагін: приватний MCP-сервер, через який AI-асистент (Claude Code) працює зі вмістом сайту —
сторінками й Gutenberg-блоками з ACF-полями, медіа, опціями, рубриками й перекладами, а адміністратори
ще й з WP-CLI. Кожен ключ доступу належить користувачу WordPress і має рівно його права. Плагін для
власних проєктів, не для публікації.

Поточна версія: **2.5.3** · PHP 8.1+ · WordPress 6.0+ · [зміни](CHANGELOG.md) · автор — [Vitalii Kaplia](https://kaplia.pro/)

Встановлення: завантажте `simple-mcp.zip` з
[останнього релізу](https://github.com/vitaliikaplia/simple-mcp/releases/latest) і встановіть через
«Плагіни → Додати новий → Завантажити плагін». Далі плагін оновлюється з GitHub сам. Ключ доступу
генерується в профілі користувача разом із готовою командою підключення для Claude Code.
