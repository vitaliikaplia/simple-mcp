# Simple MCP

Уся документація для агентів — у Memo (MCP-сервер `memo`), проєкт **#31 simple-mcp**.
Почніть з `memo_structure` для проєкту 31: картка, карта й протокол роботи.

Після кожної завершеної задачі оновлюйте записи в Memo, а не MD-файли. Перед компактом запишіть
статус задачею в кімнаті `compaction`, після компакту — прочитайте її й закрийте.
